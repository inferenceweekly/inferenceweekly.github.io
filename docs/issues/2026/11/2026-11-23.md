# #4: This week in inference
KubeCon gave inference its own day this year, and [the full playlist of Inference Day talks](youtube.com/playlist?list=PLY3atWMmCSOg) is out. Worth a look.

## :material-book-open-variant: Read

- **[180B Parameters, 32GB of RAM: Pushing MoE Inference to the Limit with Transformers](https://huggingface.co/blog/moe-expert-streaming)**, *Hugging Face Blog*.
    - Streams only the routed MoE experts from SSD through a bounded cache, so Qwen3.8-Flash-Next runs on a 32GB Mac in Transformers at 13.9 tok/s decode
- **[Inference engineering for software engineers](https://newsletter.pragmaticengineer.com/p/inference-engineering-for-software-engineers)**, *The Pragmatic Engineer*.
    - When should a team move from frontier-lab APIs to open models on inference providers or dedicated GPUs? Weighs cost, latency, and caching (paywalled after the intro)
- **[Cerebras Disaggregated Inference](https://www.cerebras.ai/blog/cerebras-launches-disaggregated-inference)**, *Hacker News (50+ points)*.
    - Prefill runs on GPUs (AMD Instinct) and decode on Cerebras CS-3, which Cerebras says gives 5X throughput per megawatt over CS-3 alone with no loss in token speed
- **[Berth: SLO-Preserving GPU Sharing Without New Preemption](https://arxiv.org/abs/2611.25091)**, *arXiv cs.DC*.
    - A user-space shim that runs best-effort work like training on a shared GPU only when inference is idle, keeping SLOs close to running alone with 2.7-3.5x the best-effort throughput of the strongest baselines
- **[[2604.07609] Blink: CPU-Free LLM Inference by Delegating the Serving Stack to GPU and SmartNIC](https://arxiv.org/abs/2604.07609)**, *arxiv.org*.
    - Moves request handling to a SmartNIC and batching/scheduling to a persistent GPU kernel, removing host-CPU interference and cutting pre-saturation P99 TTFT by up to 8.47x versus TensorRT-LLM, vLLM, and SGLang

## :material-youtube: Watch

- **[Cache Me If You Can: LLM Inference with llm-d (with fun drawings) - Alexa Griffith, Red Hat](https://www.youtube.com/watch?v=ixmKvIejJv4)**, *CNCF*.
    - A hand-drawn walkthrough of LLM inference with llm-d, including how caching fits into serving
- **[Observability for LLM Inference on... - Oscar Castillo, Genius Sports & Jeffry Hernández, Wizeline](https://www.youtube.com/watch?v=4T2887KV_WM)**, *CNCF*.
    - What to monitor when you run LLM inference in production, from Genius Sports and Wizeline
- **[Inference Is a Black Box: How We Built GPU-Aware Observability... - Henrique Santana & Danilo Souza](https://www.youtube.com/watch?v=by0-US7Kdzo)**, *CNCF*.
    - How one team built GPU-aware observability to see what inference workloads are actually doing

## :material-github: Repos

- **[pegainfer-project/pegainfer](https://github.com/pegainfer-project/pegainfer)**
    - PegaInfer is an LLM inference engine in pure Rust and CUDA with no PyTorch dependency. It has an OpenAI-compatible API and serves models from Qwen3 up to Kimi-K2.

- **[hao-ai-lab/JetSpec](https://github.com/hao-ai-lab/JetSpec)**
    - JetSpec is a speculative decoding method that drafts a tree of candidate tokens in parallel and refines it with a self-refinement step.

- **[llm-d/llm-d-kv-cache](https://github.com/llm-d/llm-d-kv-cache)**
    - The llm-d project's libraries for distributed KV cache scheduling and offloading, a good companion to the llm-d talk above.
