# Submit a link

Found an article, talk, paper or repo that inference engineers should see?

- **Open an issue** on
  [GitHub](https://github.com/inferenceweekly/inferenceweekly.github.io/issues/new?template=link-suggestion.yml)
  using the *Link suggestion* form, or
- **Reply** to any newsletter email.

Good submissions are practical, technical and about running inference in
production. Vendor content is welcome when it teaches something; pure product
announcements usually aren't included.
